## Этап 3: Реализация "слоя представления" - консоли

На этом этапе был разработан консольный пользовательский интерфейс для взаимодействия с приложением.

### Требования этапа:

*   **Разработка пользовательского интерфейса:** Создано меню и реализованы основные команды для выполнения действий пользователем в консоли. Интерфейс стремится быть интуитивно понятным.
*   **Обработка ввода пользователя:** Включена проверка ввода данных и обработка возможных ошибок с использованием исключений.
*   **Формат сдачи:** Код готов к загрузке на GitHub. Описание основных команд и их назначение приведено в этом файле (будет дополнено по мере реализации команд).

### Содержимое папки stage 3:

Папка содержит консольное C# приложение (`ConsoleApp1`) с файлами `Program.cs`, `ConsoleApp1.sln`, `ConsoleApp1.csproj` и служебными директориями `bin` и `obj`.
