## Этап 5: Реализация бизнес-слоя

На этом этапе реализуется основная бизнес-логика приложения.

### Требования этапа:

*   **Разработка бизнес-логики:** Создаются классы, реализующие логику приложения, отделенную от слоев представления и данных.
*   **Применение ООП:** В разработке классов используются принципы наследования, полиморфизма и инкапсуляции.
*   **Проверка методов:** Обеспечивается корректность работы методов бизнес-слоя.
*   **Формат сдачи:** Код готов к загрузке на GitHub. Основные классы и их функционал описаны в этом файле.

### Содержимое папки stage 5:

Папка содержит классы бизнес-логики приложения.

*   `UserService.cs` - Класс, отвечающий за логику, связанную с пользователями (регистрация, вход, управление друзьями - пока частично реализовано).
