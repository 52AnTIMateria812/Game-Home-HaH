## Этап 4: Реализация слоя работы с БД

На этом этапе был реализован слой для взаимодействия с базой данных.

### Требования этапа:

*   **Реализация классов для работы с БД:** Созданы классы (репозитории) для выполнения операций с базой данных.
*   **Реализация CRUD операций:** Реализованы базовые методы для создания, чтения, обновления и удаления данных (пока частично).
*   **Обработка ошибок БД:** Добавлена обработка ошибок, связанных с работой базы данных.
*   **Формат сдачи:** Код готов к загрузке на GitHub. Структура слоя работы с БД описана в этом файле.

### Содержимое папки stage 4:

Папка содержит классы для работы с базой данных, включая модели данных (`Models`), репозитории (`Repositories`) и вспомогательные классы/исключения (`Utils`).

*   `Models/User.cs`, `Models/Game.cs`, `Models/GameSession.cs` - Модели данных, отражающие структуру таблиц.
*   `Repositories/UserRepository.cs` - Репозиторий для работы с пользователями и их аккаунтами (реализованы не все методы).
*   `Utils/DatabaseException.cs` - Класс пользовательского исключения для ошибок БД.
